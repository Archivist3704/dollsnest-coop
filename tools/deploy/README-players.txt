Dolls Nest 联机 mod（v680）

这是什么
  让《Dolls Nest》可以两个人（最多四个）一起玩：你看到对方的机体在走动、开枪，
  敌人血量和生死两边一致。不需要管理员权限，不需要注入器，不需要 UE4SS，
  不写游戏本体的任何文件。

装什么
  把整个压缩包解压到：

      <你的 Steam 库>\steamapps\common\Dolls Nest\

  解压出来的目录是 DollsNest\Binaries\Win64\，直接和游戏里已有的那个合并（覆盖同名文件）。
  不需要自己找位置：zip 里就是这个结构。

  落位之后，DollsNest\Binaries\Win64\ 里应该多出这几个文件：

      version.dll          （让游戏自己把 mod 加载起来）
      dollsnest-coop.dll   （mod 本体）
      README.txt           （这份说明，留在那里就行）

  然后从 Steam 正常启动游戏。不要用任何“注入器”，也不需要改启动项。

菜单（F7）
  菜单文字跟着游戏的语言走（游戏里没设语言时用系统的界面语言），两台机器可以不一样。
  标题是本地化标题，它下面一行是标题的英文：

      语言      标题                    副标题
      简体中文  联机菜单                Co-op Menu
      繁體中文  連線選單                Co-op Menu
      日本語    マルチプレイメニュー    Co-op Menu
      English   Co-op Menu              （英文模式没有副标题）

  不在联机里时是三行：担任主机 / 加入房间 / 退出
  已经在联机里时是两行：继续 / 结束联机
  （英文界面下依次是 Host a session / Join a session / Quit，以及 Continue / End the session）

怎么联机
  1. 双方都装 Radmin VPN（或同类虚拟局域网），加入同一个网络。
  2. 在同一个 Win64 目录里放一个 peers.txt，写对方的虚拟局域网地址，一行一个：

         26.x.x.x

     双方都写对方。没有这个文件也能连（会走局域网广播），但在虚拟局域网上必须有它。
  3. 主机先进游戏、进到要玩的那张地图，按 F7，选第一行“担任主机”（Host a session）。
  4. 客机在 8 秒内按 F7，选第二行“加入房间”（Join a session）。
  5. 两个人必须站在同一张地图上。不同地图不会互相看见，也不会有任何提示 —— 这是设计。

怎么知道装好了
  - 启动游戏之后，Win64 目录里会出现 dsh-proxy-load.txt，里面最新一行的时间就是刚才；
    再往下应该有 “15/15 forwarded” 和 “payload loaded”。
  - 游戏里按 F7 能弹出菜单，就是加载成功了。
  - 同一个目录里还有 dollsnest-coop.log，第一屏会有 build=… 和 file sha256=…。
    两台机器的 file sha256 必须完全一样，否则不是同一个版本，连不上。

杀毒软件说它是病毒
  这是未签名的 mod，偶尔会被误报（所有这类 mod 都会）。三步：
  1. 打开杀毒软件的隔离区，把被隔离的文件还原；
  2. 把 Win64 这个目录加入排除 / 信任列表；
  3. 重新启动游戏。
  如果重启后 dsh-proxy-load.txt 里没有新的一行，就是它又被拦了。

卸载
  删掉 version.dll 和 dollsnest-coop.dll 就行，游戏会回到原样。

已知的限制（当前版本）
  - 只有在同一张地图上才会配对；换地图会断线，不会把人传送过去。
  - 在休息点补给、或者死亡，都会结束会话，需要重新按 F7。
  - 主机结束会话时，客机不会收到提示，需要自己按 F7 退出。
  - 客机联机时建议用一份存档的副本（游戏的自动存档会写进它读的那个档）。
  - 实测过的是 2 人和 3 人；第 4 个位置没有实测。

版本
  两台必须使用同一个 zip 里的两个 DLL。是不是同一份，看两台日志第一屏的
  file sha256 是不是一样。
