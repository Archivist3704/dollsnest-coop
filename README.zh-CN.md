# Dolls Nest 联机 mod

[English](README.md) | 简体中文 | [日本語](README.ja.md)

这是给人偶之巢制作的联机合作pve mod。
mod 本体是一个原生 DLL 加一个很小的加载器，以及一份在虚拟局域网时优先匹配的名单。

> **状态**：v685，在 2 台和 3 台机器上实测通过（游戏 1.3.2）。本仓库就是那一版的源码。
>
> **授权**：保留所有权利 —— **禁止商用**。详见文末「许可证」一节。

**下载：[最新发布版](../../releases/latest)**

## 给玩家

### 安装

1. 从 [Releases](../../releases/latest) 下载 `DollsNest-coop-v685.zip`，解压到你的 Steam 库目录：

   ```
   <Steam 库>\steamapps\common\Dolls Nest\
   ```

   压缩包里已经有 `DollsNest\Binaries\Win64\` 这一层，解压到那里就等于把 `version.dll` 、
   `dollsnest-coop.dll` 和 `peers.txt` 放到了应该有的位置。

2. 像平常一样从 Steam 启动游戏。

3. 确认游戏目录里出现了 `dsh-proxy-load.txt`，并且在游戏中可以按 **F7**呼出菜单。

### 联机

1. 双方都装 Radmin VPN（或同类虚拟局域网工具），进同一个网络。
2. 在 `peers.txt`文件中写所有人的虚拟局域网地址，包括自己的虚拟局域网地址，一行一个。
3. 主机在地图中，按 **F7**，担任主机。
4. 客机按 **F7**，选加入房间。
5. 两个人必须在同一张地图上 —— 不同地图无法联机。

### 限制

- 只有同图才能配对；换地图会结束联机。
- 在休息点补给、或者死亡，都会结束会话 —— 之后重新按 **F7**担任主机或加入即可。
- 主机结束会话时客机不会收到提示，需要自己退出。
- 实测过 2 人和 3 人，第 4 人没有测过。
- 主机的boss是否挑战过的状态会写入客机存档，这是为了同步进度。
- 尽管进度本身不影响联机，但还是请尽量让进度较慢的人担任主机。如果进度一致那无所谓。
- 游戏对剧情道具和进度有一套完善的保护措施，但实在怕坏档的话，请备份存档进行联机。

## 给开发者

### 构建

需要 Visual Studio 2022/2026 的生成工具（MSVC 19.5x）和 CMake 3.2x 以上。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\build\build.ps1 -BootstrapName dollsnest-coop-v685
```

产物是 `out\bin\dollsnest-coop-v685.dll`（附带 `.pdb`）。成功时打印 `[build] OK` 并以 0 退出；退出码
非 0 说明脚本拒绝交出 DLL —— 产物缺失、名字和要求的不符，或者 DLL 比源码还旧。紧邻的 `[build]`
警告会说明是哪一种。

离线测试套件会一起编出来：

```powershell
out\bin\dsh-selftest.exe
```

必须打印 `checks: 734 failures: 0`。

### 目录

| 位置 | 是什么 |
|---|---|
| `Code/dsh-bootstrap` | mod 怎么进游戏：加载器、命令通道、F7 菜单、房间发现 |
| `Code/dsh-game` | 会话本体：发什么、造什么、镜像什么 |
| `Code/dsh-reflect` | 读写游戏里的 actor —— 唯一知道游戏字段布局的地方 |
| `Code/dsh-net` | UDP 传输、会话握手、报文外壳 |
| `Code/dsh-sync` | 插值、回放钟、发送节奏 |
| `Code/dsh-platform` | 日志、hook 包装、文件哈希 |
| `Code/dsh-selftest` | 离线套件：不需要游戏的那部分 |
| `Code/dsh-proxy` | 冒充 `version.dll` 的转发壳，让游戏自己加载 mod |
| `tools/build`、`tools/deploy` | 构建、部署到游戏目录、出发布包 |

### 它大概怎么工作

主机每秒二十次采样自己机体的位置和外观，通过一套很小的 UDP 协议发出去；客机把外观拼起来，在自己的
世界里造出同一台机体，并让它保持同步。敌人的血量、任务状态、子弹和道具使用都走同一条路。主机是世界
的权威；客机报告自己那侧发生了什么，由主机裁决。
